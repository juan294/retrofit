# Analysis owners can download the self-hosted install bundle

Juan approved this access rule on 2026-11-22. A visitor with a ready analysis can download its install files from the browser that started it. The download expires with the analysis. The bundle contains a snapshot of the site's public pages and a browser assistant with read-only tools.

The visitor installs the files on a site they control. The download grants no publishing rights on Retrofit. Official Retrofit-hosted publishing and the badge still require proof of site ownership by meta tag or DNS. The private preview keeps its unofficial label.

This decision narrows the install claim requirement in the accepted 2026-11-14 design brief. The results page also lets visitors request installation by email. Opening that link prepares a message in their mail client.
