Harbor tours demo

This is a synthetic demo site. The tours, times and prices are fictional, and nothing can be booked. It exists so that agent sites can show how they ask another site's agent network, with the visitor's consent.

Tours

  • Lighthouse walk: 90 minutes on foot to the old lighthouse. Daily at 10:00 and 15:00. Price 18 demo credits. The path has 120 steps.
  • Sunset sail: 2 hours on a small sailing boat. Thursday to Sunday at 18:30. At most 12 guests. Price 45 demo credits.
  • Seal watch: 75 minutes on a covered motor boat. Daily at 11:30. Price 30 demo credits. It does not run in storms. The boat has a ramp.

Meeting point: the kiosk on Pier 2, open 09:00 to 18:00.

Bookings: the demo has no booking form and takes no bookings, payments or personal details.

For agent sites

This site publishes agent-manifest.json with the network harbor_tours, which answers from the facts on this page. Call it as https://demo-harbor.thecreativetoken.com/harbor_tours and add this origin to your allowed_peers.

The manifest also lists two conformance fixtures: harbor_invalid, which fails validation on purpose, and harbor_loop, which calls Retrofit back to test loop prevention. Retrofit's conformance page explains each one.
